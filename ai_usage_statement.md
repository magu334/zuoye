# AI Usage Statement

This project used an AI coding agent as a development assistant under a controlled workflow.

## AI Helped With
- Comparing topic options and narrowing the financial research question.
- Drafting proposal and data discovery materials.
- Creating project workflow scripts and configuration files.
- Improving section routing and output validation.
- Drafting README, demo script, prompt templates, and evaluation skeletons.
- Explaining errors and suggesting targeted repairs.

## Student Responsibilities
- Choosing the final financial problem.
- Checking whether CNINFO data matches the topic.
- Running scripts locally.
- Reviewing downloaded PDFs, parsed markdown, sections, evidence, and extracted fields.
- Filling manual evaluation gold labels.
- Explaining final method, results, errors, and limitations.

## Secret Handling
- Real API keys were used only for local testing.
- `.env.example` contains placeholders only.
- Real `.env` must not be committed or submitted.

## Verification Principle
Model output is not treated as fact unless it can be traced back to CNINFO announcement text and passes schema validation plus human review.
